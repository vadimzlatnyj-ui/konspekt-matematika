# Плоттер-конспект — заметки для работы над проектом

Приложение пишет текст, формулы, графики и рисунки в тетради пишущим XY-плоттером (GRBL, иногда Marlin) по USB.
Пользователь — русскоязычный, общается по-русски, на Windows, работает в настольной программе (Electron).
Все тексты интерфейса и комментарии в коде — по-русски.

## Как устроено

- `index.html`, `css/style.css`, `js/app.js` — интерфейс, настройки (localStorage `plotterCfg`, миграции по `cfgVer`), печать, предпросмотр.
- `js/font.js` — встроенный однолинейный шрифт; смешивание шрифтов, «небрежность» (детерминированная, `beginLayout(seed)`),
  метки выделения ``/`` (линии вне выделения помечаются точкой `[NaN, NaN]`).
- `js/customfont.js` — свои шрифты: TTF/OTF/WOFF (opentype.js), SVG, Hershey .jhf, JSON, `.gfont` (zip с файлом на букву), zip/gzip.
- `js/math.js` — разбор и вёрстка формул (подмножество LaTeX). `js/graph.js` — графики `[график: …]` с таблицей значений x/y.
- `js/layout.js` — вёрстка по клеткам и страницам, поля, разворот, `[рисунок: id; ширина N]`.
- `js/images.js` — картинка → линии (утончение Чжана–Суэна), хранение в IndexedDB.
- `js/importdoc.js` — импорт .docx (формулы OMML → LaTeX, рисунки) и PDF (pdf.js в основном потоке).
- `js/gcode.js` — порядок письма по строкам, преобразование лист → станок (угол нуля, поворот, отступ), G-code с меткой
  {page, stroke, pen, line} для каждой строки; в конце программы всегда «ручку вверх и домой».
- `js/serial.js` — Web Serial: отправка с подсчётом символов (буфер GRBL ~120 байт), статус `?`, мягкая пауза,
  «дописать строку и закончить», стоп, ожидание смены листа (M0 перехватывается).
- `desktop/` — Electron: окно, выбор порта, самообновление интерфейса с GitHub (`desktop/updater.js`).

## Обязательно после изменения файлов интерфейса

1. `node tools/manifest.js "что изменилось"` — обновить `version.json` (иначе программа у пользователя не обновится сама).
2. Закоммитить и запушить в ветку `claude/plotter-gcode-formula-app-892yqn` (она же ветка по умолчанию репозитория
   `vadimzlatnyj-ui/konspekt-matematika`). Программа берёт обновления с `raw.githubusercontent.com/…/HEAD/`;
   кэш GitHub обновляется до ~5 минут — дождаться, пока все файлы совпадут с `version.json`.
3. Изменения в `desktop/*.js` (оболочка) самообновлением не доставляются — нужна новая сборка `npm run build:win`
   и архив пользователю.

## Проверка

Проверять в Chromium через Playwright (он установлен). Для печати — имитация GRBL, подменяющая `navigator.serial`
(отвечает `ok`, статус `<Run|MPos:…>`, `$$`, байты переопределения скорости). Перед отправкой прогонять:
печать с паузами (ни одного холостого хода `G0` с опущенной ручкой), «дописать строку», печать выделенного,
продолжение после перезапуска, импорт Word/PDF, загрузку шрифтов.

## Про плоттер пользователя

XY-плоттер на алюминиевом профиле: X — вдоль балки с кареткой, Y — вдоль зажима (балка едет к себе/от себя);
бумага зажимается клипсой слева. Ноль и стрелки направлений пользователь выставлял сам («Ноль плоттера», кнопки
«▲▼/◀▶ наоборот — исправить»). Дом по умолчанию — верхний левый угол тетради («📍 Ручка на углу тетради»).
