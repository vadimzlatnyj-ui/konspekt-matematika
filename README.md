# Плоттер-конспект: формулы → G-code

Браузерное приложение: вставляете текст ответа (с формулами в LaTeX или юникоде), настраиваете тетрадь и ручку — и получаете G-code для пишущего плоттера, разбитый **по страницам**.

Ничего устанавливать не нужно: откройте `index.html` в браузере (Chrome, Firefox, Edge). Работает без интернета.

## Возможности

- **Однолинейный шрифт** (ручка проходит каждую линию один раз): кириллица, латиница, цифры, греческие буквы, математические знаки.
- **Формулы**: `$…$` в строке, `$$…$$` / `\[…\]` отдельной строкой, `\(…\)`.
  Поддерживаются `^ _ \frac \sqrt \sqrt[n]{} \left( \right) \sum \prod \int \lim \sin \log \vec \overline \hat \text{}`,
  `\begin{cases}`, `\begin{pmatrix}`/`bmatrix`/`vmatrix`, `\begin{aligned}`, греческие буквы, `\le \ge \ne \approx \infty \to \Rightarrow \in \cdot \times \pm \angle \perp \degree` и др.
  Скобки вокруг дробей растягиваются автоматически.
- В обычном тексте понимаются юникод-записи: `x²`, `a₁`, `√2`, `√(x+1)`, `≤`, `π`, `→`.
- Markdown из ответа чат-бота (`**жирный**`, `# заголовки`, списки) очищается автоматически.
- **Тетрадь**: ширина/высота (готовые форматы), размер клетки, поля, зеркальные поля на чётных страницах, привязка строк к линиям клеток.
- **Положение на столе**: X/Y левого нижнего угла листа, поворот 0/90/180/270°, отражение осей, размер стола (предупреждение при выходе за границы).
- **Ручка**: любые команды подъёма/опускания (готовые пресеты: серво `M3 S…`, ось Z, Marlin `M280`), подачи письма и холостого хода, `G0` или `G1` для перемещений.
- **Постранично**: каждая страница — отдельный файл, или все страницы одним файлом с паузой `M0` между ними (команды паузы настраиваются).
- Предпросмотр листа в клетку и вида на столе станка, показ холостых ходов, оценка времени, оптимизация порядка штрихов.
- Настройки сохраняются в браузере, их можно выгрузить/загрузить файлом `.json`.

## Как пользоваться

1. Скопируйте ответ (лучше кнопкой «Copy» — тогда формулы придут в виде `$…$`) и вставьте в поле «Текст ответа».
2. Укажите размеры тетради и поля, затем, где тетрадь лежит на столе плоттера (координаты угла и поворот).
   Проверьте вид «Стол станка»: оранжевая линия — верхний край листа.
3. Настройте команды подъёма/опускания ручки и скорости.
4. Скачайте G-code: текущую страницу, все страницы одним файлом (с паузами для перелистывания) или каждую отдельно.
5. Новая страница вручную — строка `\newpage` в тексте.

Совет: перед первой печатью запустите страницу с поднятой ручкой (или без ручки), чтобы проверить, что плоттер попадает в тетрадь.

## Файлы

- `index.html`, `css/style.css`, `js/app.js` — интерфейс
- `js/font.js` — однолинейный шрифт
- `js/math.js` — разбор и вёрстка формул
- `js/layout.js` — перенос строк и разбивка на страницы
- `js/gcode.js` — преобразование координат и генерация G-code
