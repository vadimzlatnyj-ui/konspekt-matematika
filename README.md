# Плоттер-конспект: формулы → G-code

Браузерное приложение: вставляете текст ответа (с формулами в LaTeX или юникоде), настраиваете тетрадь и ручку — и получаете G-code для пишущего плоттера, разбитый **по страницам**.

## Программа для Windows

1. Скачайте архив `Plotter-konspekt-Windows.zip` и распакуйте его в любую папку (например, «Документы»).
2. Запустите `PlotterKonspekt.exe`. Windows может предупредить «Неизвестный издатель» — нажмите «Подробнее» → «Выполнить в любом случае».
3. Подключите плоттер USB-кабелем, нажмите «🔌 Подключить» — и печатайте. На листе видно, где сейчас ручка.

Если плоттер не находится — поставьте драйвер USB-платы (у большинства плат это CH340, иногда CP2102 или FTDI).

**Программа обновляется сама**: при запуске и каждые 30 минут она проверяет GitHub (`version.json` в этом репозитории),
скачивает изменившиеся файлы интерфейса, сверяет контрольные суммы и предлагает «Обновить сейчас»
(или включает новую версию при следующем запуске). Во время печати обновление не применяется.
После изменения файлов интерфейса нужно обновить `version.json`: `node tools/manifest.js "что изменилось"`.

Собрать программу самому: `npm install`, затем `npm run build:win` (или `build:mac`, `build:linux`), результат — в папке `dist`.
Запустить без сборки: `npm start`.

Без установки можно открыть и `index.html` в Chrome / Edge / Яндекс.Браузере — работает так же, включая USB.

## Возможности

- **Однолинейный шрифт** (ручка проходит каждую линию один раз): кириллица, латиница, цифры, греческие буквы, математические знаки.
- **Формулы**: `$…$` в строке, `$$…$$` / `\[…\]` отдельной строкой, `\(…\)`.
  Поддерживаются `^ _ \frac \sqrt \sqrt[n]{} \left( \right) \sum \prod \int \lim \sin \log \vec \overline \hat \text{}`,
  `\begin{cases}`, `\begin{pmatrix}`/`bmatrix`/`vmatrix`, `\begin{aligned}`, греческие буквы, `\le \ge \ne \approx \infty \to \Rightarrow \in \cdot \times \pm \angle \perp \degree` и др.
  Скобки вокруг дробей растягиваются автоматически.
- В обычном тексте понимаются юникод-записи: `x²`, `a₁`, `√2`, `√(x+1)`, `≤`, `π`, `→`.
- **Таблица значений x и y** рядом с графиком (справа, а если не влезает — снизу): x — целые точки диапазона или свои
  (`таблица -2 -1 0 1 2`, `таблица снизу`, `без таблицы`), y — считаются сами, до сотых; для нескольких функций — строки y1, y2…
  По желанию (раздел «Почерк → Графики»): рамка вокруг графика и номер «Рис. N».
- **Графики функций** — отдельной строкой в тексте:
  ```
  [график: y = x^2 - 2x - 3; x от -3 до 5; точки (1; -4) (-1; 0) (3; 0)]
  ```
  Рисуются оси со стрелками, деления и цифры (по умолчанию 1 единица = 1 клетка, поле графика встаёт на линии клеток), кривые с правильными разрывами (`tg x`, `1/x`).
  Параметры через `;`: несколько функций (`y = sin x; y = cos x`), `x от … до …`, `y от … до …` (иначе подбирается сам),
  `точки (1; 2) (3; 4)`, `асимптоты x = 2, y = 1` (пунктир), `шаг 2` / `шаг y 5`, `размер 12x8` (в клетках), `слева`, `без цифр`, `подписать`.
  В выражениях: `+ - * / ^`, `2x`, `3sin x`, `|x|`, `sqrt abs sin cos tg ctg arcsin arccos arctg ln lg log_2 exp`, `pi`, `e`, а также `\frac{}{}` и `\sqrt{}`.
- Markdown из ответа чат-бота (`**жирный**`, `# заголовки`, списки) очищается автоматически.
- **Разворот**: раскрытая тетрадь кладётся на стол, плоттер пишет сразу на левой и правой странице.
  Между страницами — перегородка (корешок) заданной ширины, где ручка не пишет; широкие поля ставятся снаружи.
  Пауза для смены листа — только после всего разворота.
- **Рисунки → линии**: рисунки из Word (PNG/JPG внутри .docx) и свои картинки («🖼 Рисунок») превращаются в линии для ручки —
  тёмные линии утончаются до средней линии (Чжан–Суэн) и прослеживаются, светлая заливка пропускается, каждая линия рисуется
  один раз. В тексте рисунок — строка `[рисунок: id; ширина 60]` (можно поменять ширину или добавить `слева`).
  Рисунки хранятся в программе. Векторные EMF/WMF из старых версий Word не поддерживаются.
- **Отмена и возврат**: Ctrl+Z — отменить, Ctrl+Y (Ctrl+Shift+Z) — вернуть, кнопки ↶ ↷ над текстом. Отменяется всё:
  набор, вставка, открытие Word/PDF, пример, изменения настроек. Работает и в русской раскладке.
- **Приближение листа**: Ctrl + колёсико мыши над листом (к курсору); без Ctrl колёсико листает приближенный лист; перетаскивание мышью, кнопки «+ − ⤢», двойной щелчок — весь лист.
- **Импорт конспектов из Word и PDF** («📥 Открыть Word / PDF»): из `.docx` переносится текст с абзацами и списками,
  а формулы Word (OMML: дроби, степени, индексы, корни, суммы, интегралы, пределы, скобки, матрицы, системы) превращаются
  в формулы программы. Из `.pdf` — текст (строки склеиваются в абзацы, степени и индексы вида a², H₂O распознаются);
  сложные формулы из PDF переносятся только частично. Также `.txt` / `.md`. Старый `.doc` — пересохраните как `.docx`.
  PDF читается библиотекой pdf.js (Mozilla, Apache-2.0, `js/vendor/pdf*.js`).
- **Свои тетради**: размер, клетку и поля можно сохранить под своим названием («💾 Сохранить тетрадь») и потом выбирать из списка «Мои тетради».
- **Стрелки наоборот?** Кнопки «▲▼ наоборот — исправить» и «◀▶ наоборот — исправить» переключают угол нуля плоттера — исправляются и стрелки, и печать.
- **Тетрадь**: ширина/высота (готовые форматы), размер клетки, поля, зеркальные поля на чётных страницах, привязка строк к линиям клеток.
- **Положение на столе**: X/Y левого нижнего угла листа, поворот 0/90/180/270°, отражение осей, размер стола (предупреждение при выходе за границы).
- **Ручка**: любые команды подъёма/опускания (готовые пресеты: серво `M3 S…`, ось Z, Marlin `M280`), подачи письма и холостого хода, `G0` или `G1` для перемещений.
- **Свои шрифты**: «📂 Загрузить шрифт» в разделе «Почерк». Однолинейные Hershey `.jhf` и SVG-шрифты для плоттеров
  (Hershey Text, EMS) пишутся одной линией; обычные `.ttf` / `.otf` / `.woff` — по контуру букв.
  Поддерживается `.gfont` (рукописные шрифты: zip, в нём по файлу на букву с линиями). Формат определяется по содержимому, так что подойдёт и файл `.font` (в том числе упакованный в zip/gzip, и JSON
  других программ с SVG-путями или штрихами букв). Недостающие буквы берутся из встроенного шрифта.
  Формулы: по умолчанию встроенным шрифтом, а цифры в них — из выбранного (можно «полностью встроенным» или «полностью выбранным»).
  Шрифты сохраняются в программе. Свой JSON-формат: `{"glyphs": {"А": [ширина, "x,y x,y|x,y …"]}}` (высота заглавных 9, базовая линия 0).
- **Скорость письма в мм/мин (до 10000)** — меняется прямо во время печати: подставляется в ещё не отправленные линии рисования;
  холостые ходы и движения оси Z идут со своей скоростью (быстрый Z пропускает шаги, и ручка «уползает» вверх).
- **Угол нуля плоттера** (↙ ↖ ↘ ↗): где у плоттера X0 Y0; от него же измеряется отступ тетради. Вид «Стол станка» и стрелки
  всегда показаны как плоттер выглядит сверху. **Точка дома** по умолчанию — левый верхний угол поля (можно другой угол или свою точку).
- **Рабочее поле и точка дома**: размер поля вводится вручную или читается из GRBL (`$130`/`$131`); перед печатью
  проверяется, что всё помещается. Стрелками (шаг 0,1–50 мм) ручка подвозится в нужное место, «📍 Запомнить: дом здесь»
  сохраняет точку дома, «🏠 Ручку домой» возвращает туда, «Ноль плоттера здесь» делает текущую точку нулём (GRBL `G10 L20`, Marlin `G92`).
- **Автоподключение**: программа запоминает последний плоттер (по USB-идентификаторам платы), подключается к нему при запуске
  и сама подключается, когда плоттер включают или подключают кабелем. Отключается галочкой в панели плоттера.
- **Мягкая пауза**: плоттер дописывает текущий отрезок, останавливается и поднимает ручку (серво не гудит, нет клякс);
  «Продолжить» опускает ручку, только если она была внизу, и печать идёт с того же места.
- **Модель ручки** в симуляции и во время печати: зелёная — пишет, красная — поднята.
- **«Стоп»** плавно тормозит без потери координат, поднимает ручку и возвращает её в точку старта.
- **Мастер настройки ручки**: выбираете, как плоттер поднимает ручку (серво `M3 S`, `M5`/`M3`, ось Z, `M280`, соленоид),
  подбираете числа и сразу проверяете кнопками «▲ поднять» / «▼ опустить». При подключении к GRBL программа читает настройки
  и предупреждает, если включён лазерный режим (`$32=1`), из-за которого серво не работает, — и выключает его одной кнопкой.
- **Постранично**: каждая страница — отдельный файл, или все страницы одним файлом с паузой `M0` между ними (команды паузы настраиваются).
- **Порядок письма по строкам**: ручка пишет строку за строкой сверху вниз, слева направо (можно переключить на «кратчайший путь»).
  Строки, по которым идёт ручка, показаны на листе зелёными линиями с номерами.
- **Точка старта ручки** (X/Y станка, где стоит поднятая ручка перед запуском) — зелёный кружок на предпросмотре, пунктиром показан путь до первого штриха.
  В конце программы и между страницами ручка возвращается в старт (`{startX}`, `{startY}` в шаблонах).
- **Начать с клетки №** — чтобы дописать на частично исписанной странице.
- **Симуляция**: кнопка «▶ Симуляция» и ползунок показывают, как движется ручка (синяя — пишет, красная — поднята), скорость ×1…×100.
- **Печать прямо из приложения по USB с показом ручки в реальном времени** (Chrome / Edge / Яндекс.Браузер на компьютере, Web Serial):
  подключение к GRBL или Marlin, печать страницы или всех страниц, пауза, продолжение, стоп, кнопки «Поднять/Опустить ручку» и «Ручку в старт».
  Во время печати на листе виден кружок ручки по координатам, которые сообщает плоттер (синий — пишет, красный — поднята),
  уже написанное — тёмным, оставшееся — серым. Между страницами печать сама встаёт на паузу и ждёт, пока вы смените лист.
- Предпросмотр листа в клетку и вида на столе станка, показ холостых ходов, оценка времени, оптимизация порядка штрихов.
- Настройки сохраняются в браузере, их можно выгрузить/загрузить файлом `.json`.

## Как пользоваться

1. Скопируйте ответ (лучше кнопкой «Copy» — тогда формулы придут в виде `$…$`) и вставьте в поле «Текст ответа».
2. Укажите размеры тетради и поля, затем, где тетрадь лежит на столе плоттера (координаты угла и поворот).
   Проверьте вид «Стол станка»: оранжевая линия — верхний край листа.
3. Настройте команды подъёма/опускания ручки и скорости.
4. Скачайте G-code: текущую страницу, все страницы одним файлом (с паузами для перелистывания) или каждую отдельно.
5. Или печатайте прямо отсюда: «Печать на плоттер по USB» → «Подключить» → выбрать порт → «Печатать эту страницу».
   Программу-отправитель (UGS, Candle и т.п.) при этом закройте: порт может занимать только одна программа.
6. Новая страница вручную — строка `\newpage` в тексте.

Совет: перед первой печатью запустите страницу с поднятой ручкой (или без ручки), чтобы проверить, что плоттер попадает в тетрадь.

## Файлы

- `index.html`, `css/style.css`, `js/app.js` — интерфейс
- `js/font.js` — однолинейный шрифт
- `js/math.js` — разбор и вёрстка формул
- `js/graph.js` — графики функций
- `js/layout.js` — перенос строк и разбивка на страницы
- `js/gcode.js` — преобразование координат и генерация G-code
- `js/customfont.js`, `js/vendor/opentype.min.js` (MIT) — загрузка своих шрифтов
- `js/importdoc.js` — импорт из Word / PDF
- `js/images.js` — рисунки: картинка → линии
- `js/serial.js` — отправка G-code на плоттер по USB и чтение координат
- `desktop/main.js`, `package.json` — настольная программа (Electron)
